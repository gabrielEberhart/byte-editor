# Keymappings

When highlighting a hexadecimal value, press a value key
(<kbd>0</kbd>-<kbd>9</kbd>, <kbd>a</kbd>-<kbd>f</kbd>) to overwrite the value.

Other keys have similar actions; refer to the table below.

| Key | Action |
|-----|:-------|
| q | Exit file |
| w | Write to file |
| u | Undo last change |
| h | Move left one hexadecimal |
| j | Move down one line |
| k | Move up one line |
| l | Move left one hexadecimal |
